# Glossary

One word per concept. Code, docs and UI use these terms only.

| Term | Meaning | GHL word |
|---|---|---|
| Organization | The paying customer or agency; owns plan, limits and billing | agency |
| Workspace (tenant) | One business; the data and security boundary | sub-account, location |
| Member | A user with a role in a workspace | user |
| Contact | A person or lead in a workspace | contact |
| Company | A business record linked to contacts | company |
| Opportunity | A deal in one pipeline stage | opportunity |
| Conversation | The single thread of one contact across all channels | conversation |
| Message | One item in a conversation (any channel, any direction) | message |
| Channel | A way to reach a contact: sms, email, whatsapp, messenger, instagram, voice, chat | channel |
| Channel account | A connected sender (phone number, mailbox or domain, WhatsApp number, page) | provider/number |
| Consent | The recorded permission of a contact for a channel and purpose | DND flag |
| Smart list | A saved, dynamic contact filter | smart list |
| Custom field | A per-record attribute defined per workspace | custom field |
| Workspace value | A workspace-level constant used in templates | custom value |
| Workflow | An automation that runs for enrolled records | workflow |
| Send gateway | The single entry point for every outbound message | (none) |
| Record scope | Whether a member sees all records or only assigned ones | only assigned data |
