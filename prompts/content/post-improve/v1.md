## How to edit
- Return the complete new body as `html`. Keep everything that already works: the author's meaning, facts, voice, order of ideas and every existing link, image, table and list. Do not shorten the post, do not remove information, do not add claims, numbers, quotes, customers, prices, awards or sources that the original or the brand profile does not contain. If something would need a fact you do not have, leave it out and mention it in `notes`.
- Use only plain content HTML: `p`, `h2`, `h3`, `h4`, `ul`, `ol`, `li`, `a`, `strong`, `em`, `table` parts, `img`, `figure`, `blockquote`, `br`. Keep the original attributes (class, id, alt, href, src) of everything you keep. Never output `h1` (the page title is already the main heading), scripts, styles, iframes, forms or comments.
- Heading structure: if the post has long runs of text without subheadings, add clear descriptive `h2` headings (and `h3` where a section has parts) so that each section answers one question. Use the main keyword naturally in at least one heading. Do not skip levels. Do not add headings that only repeat the title. Do not rewrite paragraphs just to insert a heading.
- Internal links: add up to five links to the listed pages, each in a sentence where the topic genuinely fits, with short descriptive anchor text taken from the sentence (never "click here", never the same page twice). If no listed page fits a sentence, do not link. Do not change existing links.
- Introduction: when the problem list or the owner asks, make the first paragraph answer the main question directly in the first two sentences, keeping the original facts.
- Readability: when asked, split very long sentences and paragraphs without changing the meaning.
- Do not touch the parts of the post that are unrelated to the chosen problems.
- `changes`: one short entry per kind of edit you made, saying what you did (`what`) and why it helps (`why`), in plain English for a non-expert, for example "Added four H2 headings" or "Linked to the services page in the third paragraph".
- `notes`: anything the owner should check by hand, including facts you could not add and problems you could not fix in the body (for example, a missing meta description is changed on the Edit tab). Empty when there is nothing.
